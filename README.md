# 胡言研究院 · 整活演讲生成系统

一个"一本正经胡说八道"的 PPT 生成器：输入主题，现场编一套带假数据、假图表、假引用的幻灯片，可全屏放映直接开讲。还有"现场抽题 + 即兴计时"模式，适合即兴演讲比赛。

整个应用就是**一个 `index.html`**，没有构建步骤。

---

## 你需要准备

一个 **Anthropic API Key**（在 https://console.anthropic.com 注册后创建，形如 `sk-ant-...`）。
Key 只会保存在你自己浏览器里，不上传、不写进代码。每次生成会消耗少量 API 额度。

---

## 怎么运行（三选一）

### 方式 A：GitHub Pages（最推荐，最稳）
1. 新建一个仓库，把 `index.html` 传上去。
2. 仓库 **Settings → Pages**，Source 选 `main` 分支、根目录，保存。
3. 等一两分钟，访问它给的网址（形如 `https://你的用户名.github.io/仓库名/`）。
4. 打开后点右上角 **⚙ API 设置**，填入你的 Key，开始生成。

### 方式 B：本地起个小服务器
在 `index.html` 所在文件夹打开终端：
```bash
python3 -m http.server 8000
```
浏览器访问 `http://localhost:8000` 即可。

### 方式 C：直接双击 index.html
界面能打开，但**生成功能可能被浏览器的安全策略（CORS）拦住**，因为是从本地 `file://` 直接调用接口。如果点生成报"连不上"，请改用方式 A 或 B。

## 使用说明

- **生成幻灯片**：填主题（或点"随机选题"从词库现拼），选风格 / 胡说程度 / 受众难度 / 页数，点生成。
- **风格**：学术研讨、商业路演、政府白皮书、TED 演讲、抽象搞怪。
- **受众难度**：小学生（大白话）、大众、烧脑（术语拉满）。
- **现场抽题**：老虎机式抽题 + 即兴计时器，比赛现场用。
- **全屏放映**：点击左右半屏翻页，或用键盘 ← → / 空格；Esc 退出。
- **复制讲稿**：把整套文字拷走。

想存成 PPT/PDF：放映时用录屏或截图最省事；或浏览器打印当前页。

---

## 安全与费用提醒

- **不要**把你的 API Key 写死在 `index.html` 里再提交到公开仓库——任何访客都能看到并盗用。本项目让每位用户在页面里各自填自己的 Key，正是为此。
- 部署到公开网址后，访客用的是他们自己填的 Key，花的是他们自己的额度。
- 模型可在"API 设置"里切换（Sonnet 便宜快、Haiku 最省、Opus 最强）。如果某个模型报 400，多半是你的账号还没该模型权限，换一个即可。
